# PHIL 270 · Symbolic Logic

Practice apps for every class of PHIL 270: definitions with examples, exercises that explain every wrong answer, and a 10-question test at the end of each class.

Open `index.html` for the list of classes. Each class opens with a class code from the teacher; progress is saved on each device.

The apps are generated from `phil270-src` (engine + one data file per class).
